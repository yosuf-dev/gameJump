## 🎮 About

**Vertical Jump Challenge** is a browser-based platform game developed as a **Front-End Speed Challenge**. The objective is simple:

> **Jump higher. React faster. Reach the finish line.**

Although the gameplay is straightforward, the project focuses on writing **clean, maintainable, and high-performance code**, while implementing real-time collision detection, smooth animations, and responsive controls without relying on heavy game engines.

---

## ✨ Highlights

* ⚡ 60 FPS animation using `requestAnimationFrame`

* 🦘 Physics-based jumping system
* 🧩 Component-driven architecture

* 🚀 Fast startup powered by Vite

## 🎯 Game Mechanics

The project includes several real-time gameplay systems:

* Character movement
* Gravity simulation
* Jump mechanics
* Collision detection
* Platform interactions
* Level completion
* Game state management
* Animation loop
* Keyboard event handling

Every frame is calculated with `requestAnimationFrame` to ensure smooth gameplay and optimal rendering performance.
